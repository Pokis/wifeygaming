## 🌟 Overview & Purpose

This project is a bespoke web experience built for a non-gamer partner. Instead of intimidating stats, complex mechanics, or rigid gamer roles, every game is presented through:

* **Witty & Affectionate Pitches**: Focused on shared moments, laughs, and cozy atmospheres.
* **"Ways We Can Play" Highlights**: Open checklists of relaxing things to do (decorating homes, taming animals, exploring scenic islands, solving mystery puzzles).
* **Non-Gamer Friendly Gauges**: *Pace*, *Snack & Break Friendliness (up to 10/10)*, and *Learning Curve*.
* **Zero Jargon**: Plain-English explanations of what the game actually feels like.

## 🚀 Interactive Features

1. **💌 Interactive Wishlist**:
   - Tap the heart icon on any game card to save favorites.
   - Saved locally in the browser (`localStorage`).
   - Slide-out drawer with a **"Copy Date Night Ideas"** button to paste a sweet message directly into WhatsApp or iMessage.
2. **🎲 Date Night Roulette**:
   - An animated random adventure picker that shuffles through the catalog with celebratory confetti!
3. **💡 "Suggest a Game" Form**:
   - Simple modal form to add new game ideas seen on social media or YouTube directly into the collection.
4. **🔍 Dynamic Search & Vibe Filters**:
   - Filter chips for *Cozy & Relaxed*, *Puzzles & Big Brain*, *Building & Creating*, *Pure Fun & Chaos*, and *Epic Adventures*.
   - Status toggle (*Ready to Play* vs. *Upcoming Hype*).
5. **✨ Rich Details & Embedded Trailers**:
   - Full responsive YouTube gameplay trailer embeds, screenshots, direct YouTube player action button, and Steam store links.

## ⚡ Quick Start & Deployment

### Local Preview (Zero Setup)
Simply double-click `index.html` in your file explorer, or run a lightweight local server:
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000`.

### 1-Minute GitHub Pages Deployment
1. Create a repository on GitHub (e.g. `coop-games`).
2. Push your files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Our Co-Op Lounge"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```
3. Go to **Settings > Pages** in your GitHub repository.
4. Set source to **Deploy from a branch** (`main` / root), then click **Save**.
5. Your live site will be ready at `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/`!

## 📋 What's Missing & Future Roadmap

To keep this project lightweight and maintenance-free, it is intentionally built as a **pure client-side static site**. Here is a clear breakdown of potential future enhancements and architectural considerations:

### 1. Cross-Device Real-Time Wishlist Syncing *(Currently Local)*
* **Current Behavior**: Wishlist items and custom games are stored in the user's browser via `localStorage`. If she opens the site on her phone, her bookmarks stay on her phone.
* **Potential Upgrade**: Integrate a lightweight serverless backend (e.g., Supabase, Firebase, or a simple JSON KV store) or URL parameter state sharing (`?wishlist=valheim,palworld`) so wishlist selections sync seamlessly across both your phone and PC.

### 2. Progressive Web App (PWA) & Offline Mode
* **Potential Upgrade**: Add a `manifest.json` and a simple Service Worker so the site can be installed as a standalone app icon on iOS / Android home screens.

### 3. Date Night Reminder / Calendar Export
* **Potential Upgrade**: An "Add to Calendar" button (`.ics` / Google Calendar link) when a game is chosen through the Date Night Roulette (e.g., *"Gaming Date Night: Valheim & Pizza"*).

### 4. Interactive Sound Effects
* **Potential Upgrade**: Add optional, cute retro 8-bit sound effects (subtle click blips and fanfare on roulette spin) using Web Audio API with a mute toggle.

### 5. Automated Discord / Telegram Webhook Notifications
* **Potential Upgrade**: When she saves a game or spins the roulette, an optional webhook could ping a private Discord channel or Telegram chat with *"She just picked Valheim for date night!"*.
